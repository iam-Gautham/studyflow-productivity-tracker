# StudyFlow

## Smart Study & Productivity Tracker

StudyFlow is a web-based productivity platform designed to help students stay organized, focused, and consistent in their learning journey.

### Features

* Task Management
* Task Completion Tracking
* Daily Study Goals
* Pomodoro Focus Timer
* Study Streak Monitoring
* Productivity Analytics Dashboard
* Focus Score Calculation
* Dark Mode Support
* Local Storage Persistence

### Problem Statement

Students often struggle with time management, task organization, and maintaining consistent study habits.

### Solution

StudyFlow combines task tracking, focus sessions, progress analytics, and habit-building features into a single lightweight platform that encourages productive study routines.

### Tech Stack

* HTML5
* CSS3
* JavaScript
* Chart.js
* LocalStorage

Human Experience & Productivity
